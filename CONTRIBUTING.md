# Contributing to MachPulse

## Branches

### main

Stable and demo-ready code.

### develop

Shared integration branch.

### feature/\*

Individual feature development.

### fix/\*

Bug fixes.

## Development Flow

feature branch
↓
Pull Request
↓
develop
↓
Testing
↓
main

## Main Feature Branches

- `feature/android-sensors`
- `feature/ml-pipeline`
- `feature/backend-frontend-ai`

## Commit Messages

Use clear commit messages.

### Features

`feat: add accelerometer streaming`

`feat: implement FFT features`

`feat: add anomaly detection`

`feat: add machine health scoring`

### Fixes

`fix: handle websocket reconnect`

`fix: validate sensor payload`

### Documentation

`docs: update setup instructions`

### Maintenance

`chore: update dependencies`
